# Panduan Letak Gambar

Letak fail gambar sebenar di sini dengan nama yang SAMA seperti di bawah
(website akan auto-guna gambar ni; jika tiada, placeholder/design asal akan dipaparkan):

- couple.jpg        → Gambar pasangan (Hero/Couple section)
- father.jpg        → Gambar bapa pengantin lelaki
- mother.jpg        → Gambar ibu pengantin lelaki
- duitnow-qr.png    → Gambar QR code DuitNow
- og-cover.jpg      → Gambar untuk preview bila link dikongsi (WhatsApp/FB)
- monogram.png      → Logo/initial sendiri untuk splash screen (jika tiada, design bulatan "A ♡ S" asal dipaparkan)
- splash-bg.jpg     → Gambar latar untuk splash screen SAHAJA / pembukaan jemputan (jika tiada, latar watercolor asal dipaparkan)

Format disyorkan: JPG/WebP untuk foto, PNG (transparent) untuk logo/QR code.
Saiz disyorkan:
- couple.jpg ~ 800x1000px
- father.jpg / mother.jpg ~ 600x600px (persegi)
- og-cover.jpg ~ 1200x630px
- monogram.png ~ 400x400px (transparent, akan dipaparkan dalam bulatan ~128px)
- splash-bg.jpg ~ 1200x1600px (akan jadi latar penuh skrin pembukaan)
