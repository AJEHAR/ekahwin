# Panduan Letak Lagu

Letak fail lagu di sini dengan nama:

- song.mp3 → Muzik latar untuk website (loop berulang)

Format: MP3 disyorkan (paling serasi semua browser/telefon).
Saiz: elakkan fail terlalu besar (>5MB) supaya tak lambat loading — 
kalau lagu asal besar, boleh compress guna tool online (contoh: 
"mp3 compressor" di Google) tanpa jejaskan kualiti ketara.

Nota lesen: pastikan awak ada hak untuk guna lagu ni (personal use 
untuk kad kahwin sendiri biasanya okay, tapi elok semak sumber lagu).

Jika fail ni tiada, butang muzik TIDAK akan dipaparkan langsung 
(auto-hide, tak akan nampak rosak).
